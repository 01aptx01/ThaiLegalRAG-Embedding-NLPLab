## เกี่ยวกับโปรเจกต์

โปรเจกต์นี้ทดลองว่าเมื่อใช้คำถามและคลังกฎหมายชุดเดียวกัน วิธีค้นแบบไหนพามาตราที่เกี่ยวข้องขึ้นมาอยู่ในอันดับต้น ๆ เมื่อได้ผลค้นแล้ว ระบบจะส่งตัวบทให้ Typhoon สร้างคำตอบภาษาไทย โปรแกรมตรวจว่ารหัสที่คำตอบอ้างอยู่ในชุดตัวบทที่ส่งให้โมเดลหรือไม่ จากนั้นคนตรวจอ่านว่าตัวบทรองรับข้อความในคำตอบจริงหรือไม่

คลังที่ใช้คือชุด CCL จาก NitiBench หน่วยที่ค้นคือ **หนึ่งมาตราต่อหนึ่งรายการ** คำตอบบนหน้าเว็บใช้สำหรับทดลองกับคลังนี้ เมื่อนำข้อมูลไปอ้างอิง ให้ตรวจตัวบทฉบับปัจจุบันกับแหล่งทางการด้วย

![หน้าเว็บ Thai Legal RAG ที่เชื่อมต่อ API และโหลดคลังกฎหมาย 5,127 มาตราแล้ว](docs/screenshots/overview.png)

ภาพในเอกสารนี้จับจากแอปที่รันจริงบน CPU ในโหมด `--retrieval-only` โดยสร้างดัชนีด้วย `--no-dense` จึงใช้ Binary BoW, TF-IDF และ Word2Vec ได้ ส่วน BGE-M3 และ Typhoon ยังไม่เปิดใช้งาน ดู [ที่มาของภาพและผลทดลอง](docs/screenshots/README.md)

## ตัวอย่างผลรันจริง

### 1. หน้าตาข้อมูลที่โหลดมา

| ชุดข้อมูลและ split | จำนวนแถวที่โหลด | ฟิลด์และค่าจากแถวจริง |
| --- | ---: | --- |
| NitiBench Statute · `ccl` | 5,127 | `law_name` พระราชบัญญัติหลักทรัพย์และตลาดหลักทรัพย์ พ.ศ. 2535<br>`section_num` 218/18<br>`section_content` “…ให้ผู้จัดการกองทุนเป็นผู้บังคับบัญชาพนักงานและลูกจ้างของกองทุน…” |
| WangchanX Legal ThaiCCL RAG · `train` (pilot) | 8,211 | `question` “ผู้จัดการกองทุนต้องปฏิบัติอย่างไร?”<br>`positive_contexts[0].metadata` เก็บชื่อกฎหมายและเลขมาตรา 218/18<br>`positive_answer` “ผู้จัดการกองทุนจะต้องเป็นผู้บังคับบัญชาพนักงานและลูกจ้างของกองทุน…” |
| NitiBench · `ccl` (test) | 3,729 | `question` “ถ้ามีมติของที่ประชุมใหญ่ให้อำนาจผู้ชำระบัญชีให้ชำระบัญชีแยกกันได้ต้องนำความไปจดทะเบียนภายในกี่วัน”<br>`relevant_laws[0].section_num` 1262 แห่งประมวลกฎหมายแพ่งและพาณิชย์<br>`reference_answer` “ต้องนำความจดทะเบียนภายในสิบสี่วันนับแต่วันลงมติ” |

คลังตัวบทเก็บ **หนึ่งมาตราต่อหนึ่งรายการ** ส่วนสองชุดคำถามเก็บคำถามพร้อมหลักฐานและคำตอบอ้างอิง สำหรับตัวอย่างถัดไปใช้ `pilot-04144` เป็นคำถาม **q** และมาตรา 218/18 เป็นตัวบท **d** ซึ่งระบบจับคู่เป็น `S00755` เครื่องหมาย … ในตารางแสดงข้อความที่ย่อไว้ [แถวข้อมูลจริงและผลจับคู่](docs/examples/run/dataset.json)

### 2. คำถามและตัวบทกลายเป็นเวกเตอร์อย่างไร

R1–R3 ใช้ `newmm` ตัดคำถามนี้เป็น **ผู้จัดการ / กองทุน / ต้อง / ปฏิบัติ / อย่างไร / ?** ส่วน R4 ใช้ tokenizer ของ BGE-M3 เอง ทุกวิธีหารเวกเตอร์ด้วยความยาว L2 เพื่อให้มีความยาวประมาณ 1 ก่อนเทียบ [รายละเอียดเวกเตอร์จากรอบรัน](docs/examples/run/embeddings.json)

| วิธีและขนาดเวกเตอร์ | ตัวอย่างคำนวณจากคำถาม **q** | ตัวอย่างคำนวณจากมาตรา **d** |
| --- | --- | --- |
| **R1 · Binary BoW (7,046 มิติ)** | ช่องคำว่า “กองทุน” เป็น 1 เพราะพบคำนี้ คำถามมี 5 ช่องที่เป็น 1 จึงได้ $1/\sqrt{5} \approx 0.4472$ | มาตรามี 47 ช่องที่เป็น 1 ช่อง “กองทุน” จึงได้ $1/\sqrt{47} \approx 0.1459$ |
| **R2 · TF-IDF (7,046 มิติ)** | “กองทุน” พบ 1 ครั้งในคำถาม และอยู่ใน 149 จาก 5,127 มาตรา จึงได้ IDF $1+\ln((1+5127)/(1+149)) \approx 4.5318$ น้ำหนักช่องนี้หลัง normalize คือ $(1\times4.5318)/10.0685 \approx 0.4501$ | “กองทุน” พบ 9 ครั้งในมาตรานี้ น้ำหนักหลัง normalize คือ $(9\times4.5318)/52.3724 \approx 0.7788$ |
| **R3 · Word2Vec Skip-gram (150 มิติ)** | เฉลี่ยเวกเตอร์ของ 5 คำที่โมเดลรู้จัก โดย `?` อยู่นอกคลังคำ พิกัดดัชนี 1 เฉลี่ยจาก $(-0.5891-0.8233-0.0937-0.7078-0.1276)/5 \approx -0.4683$ แล้วหารด้วย 2.1029 ได้ $-0.2227$ | เฉลี่ยเวกเตอร์จาก 74 tokens ของมาตรา พิกัดเดียวกันได้ $-0.5363/1.7410 \approx -0.3080$ |
| **R4 · BGE-M3 (1,024 มิติ)** | Transformer รับ 9 tokens รวม token พิเศษ แล้วใช้เวกเตอร์จากตำแหน่งแรก (CLS pooling) พิกัดดัชนี 386 ก่อนและหลัง normalize คือ $6.0815/26.2848 \approx 0.2314$ | ใช้ขั้นตอนเดียวกันกับ 97 tokens ของมาตรา พิกัดเดียวกันได้ $6.1723/26.0231 \approx 0.2372$ |

พิกัดของ R1–R2 ผูกกับคำใน vocabulary ส่วนพิกัดของ R3–R4 เป็นมิติที่โมเดลเรียนรู้ ค่าดัชนีในตารางเริ่มนับจาก 0 [คู่มือการสร้างเวกเตอร์](docs/retrieval.md)

### 3. แทนค่า cosine แล้วจัดอันดับ

Cosine คือ $\frac{q\cdot d}{\lVert q\rVert_2\lVert d\rVert_2}$ เมื่อใช้เวกเตอร์ที่ normalize แล้วจึงคูณพิกัดตรงกันและรวมผลคูณได้เลย ตัวอย่างด้านล่างเทียบ **คำถามเดิมกับมาตรา `S00755` เดิม** ในเวกเตอร์ของแต่ละวิธี [คะแนนและผลคูณที่บันทึกไว้](docs/examples/run/rankings.json)

| วิธี | ผลคูณพิกัดจริงของ **q × d** | ผลรวมพิกัดอื่น | Cosine กับ `S00755` |
| --- | --- | ---: | ---: |
| R1 · Binary BoW | ดัชนี 2046, 3379, 4217 ให้ $0.447214 \times 0.145865$ เท่ากันทั้งสามช่อง จึงได้ $3 \times 0.065233$ | 0 | **0.1957** |
| R2 · TF-IDF | $(0.450099 \times 0.778779) + (0.422525 \times 0.243690) + (0.185930 \times 0.035745)$ | 0 | **0.4601** |
| R3 · Word2Vec | ดัชนี 1 และ 68 ให้ $(-0.222693 \times -0.308015) + (0.188432 \times 0.233029)$ | 0.714615 จากอีก 148 พิกัด | **0.8271** |
| R4 · BGE-M3 | ดัชนี 386 และ 297 ให้ $(0.231371 \times 0.237185) + (-0.146826 \times -0.156716)$ | 0.589190 จากอีก 1,022 พิกัด | **0.6671** |

ตัวเลขในตารางปัดเพื่อให้อ่านง่าย ระบบใช้ค่าก่อนปัดในการเรียงจากคะแนนมากไปน้อยภายในแต่ละวิธี หากคะแนนเสมอกันจะใช้ลำดับเดิมในคลัง ตัวอย่างอันดับต้น ๆ ที่ได้จริง [ตารางอันดับและหลักฐานของข้อ pilot](docs/examples/run/cases.md#pilot-04144)

| วิธี | อันดับ 1 | อันดับ 2 | อันดับของ `S00755` |
| --- | --- | --- | ---: |
| R1 · Binary BoW | `S04712` · 0.2902 | `S03802` · 0.2176 | **6** |
| R2 · TF-IDF | `S04693` · 0.4862 | `S04684` · 0.4611 | **3** |
| R3 · Word2Vec | `S04684` · 0.8416 | `S00755` · 0.8271 | **2** |
| R4 · BGE-M3 | `S00755` · 0.6671 | `S00754` · 0.6533 | **1** |

รอบสาธิตใช้คำถาม 2 ข้อและจัดอันดับบนตัวบท 72 รายการชุดเดียวกันจากคลัง 5,127 มาตรา ระบบพิจารณาห้าอันดับแรกสำหรับส่งให้ Typhoon ดังนั้น `S00755` จาก R1 จึงอยู่นอกช่วงนี้ [ผลรันและคำตอบ Typhoon](docs/examples/run/cases.md) · [ตารางข้อมูลและเวกเตอร์ฉบับละเอียด](docs/examples/output_preview.md) · [ขอบเขตและรุ่นข้อมูล](docs/examples/run/manifest.json)

## สิ่งที่ทำได้

### Playground

พิมพ์คำถาม เลือกวิธีค้น และเปิดอ่านตัวบท เมื่อเปิด Generator จะกดรหัสอ้างอิงในคำตอบเพื่อกลับไปดูหลักฐานได้ ภาพนี้ค้นคำถาม “บุคคลบรรลุนิติภาวะเมื่ออายุเท่าใด” ด้วย TF-IDF และเปิดรายการหลักฐานที่ API ส่งกลับจริง

![Playground หลังค้นด้วย TF-IDF พร้อมตัวบทและเลขมาตราที่ค้นได้](docs/screenshots/playground.png)

### Compare

ส่งคำถามเดียวกันให้ Binary BoW, TF-IDF, Word2Vec หรือ BGE-M3 แล้วดูอันดับมาตราและเวลาที่ใช้แต่ละวิธี ภาพนี้เปรียบเทียบสามวิธีที่เปิดใช้งานบน CPU ส่วน R4 ยังไม่มีผลเพราะไม่ได้สร้างดัชนี BGE-M3

![Compare แสดงผลค้นสามวิธีและตารางเปรียบเทียบรหัสมาตรากับเวลาค้นจริง](docs/screenshots/compare.png)

### Evaluate

เปิดตารางคะแนนจากรอบทดลองที่บันทึกไว้ ภาพนี้ใช้ผลที่คำนวณจริงจากคำถาม pilot 40 ข้อด้วย seed 42 สำหรับสามวิธีบน CPU เป็นรอบสำหรับประกอบภาพ ไม่ใช่ผล benchmark ครบสี่วิธี มี [ผลรายข้อและ manifest](docs/screenshots/evaluation/) ให้ตรวจสอบ

![Evaluate แสดง Recall, Hit, nDCG และ MRR จากรอบ pilot 40 ข้อสำหรับ R1 ถึง R3](docs/screenshots/evaluate.png)

### History

เก็บรายการที่เพิ่งรันระหว่างเปิดหน้านั้น ภาพนี้แสดงคำถามจาก Playground และ Compare ที่รันก่อนจับภาพ ประวัติอยู่เฉพาะ session และหายเมื่อรีเฟรชหรือปิดหน้า

![History แสดงประวัติการค้นและการเปรียบเทียบที่เพิ่งรันใน session เดียวกัน](docs/screenshots/history.png)

นอกจากหน้าเว็บ ยังมี **คำสั่งทดลอง** สำหรับรันบนชุดคำถามที่มีคำตอบและมาตราอ้างอิง บันทึกผลรายข้อ และส่งออกไฟล์ให้คนตรวจคำตอบโดยซ่อนชื่อวิธีค้น ดู [การทดลองและการประเมินผล](docs/evaluation.md)

## เริ่มใช้งาน

ใช้ Python 3.10 ขึ้นไป สำหรับหน้าเว็บให้เตรียม Node.js ด้วย ตัวอย่างนี้ใช้ Node.js 22 และรันบน CPU เพื่อทดลองค้นมาตราก่อน

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -e ".[web]"
cd frontend
npm ci
npm run build
cd ..
thai-legal-rag-web build-index --no-dense --device cpu
thai-legal-rag-web serve --retrieval-only --device cpu
```

เปิด [http://127.0.0.1:8000](http://127.0.0.1:8000) ดัชนีที่สร้างแล้วใช้ซ้ำได้ ครั้งถัดไปเริ่มที่คำสั่ง `serve` ได้เลย สำหรับ PowerShell หรือการเปิด BGE-M3 และ Typhoon ดู [คู่มือเริ่มใช้งาน](docs/getting-started.md)

![ผลคำสั่ง build หน้าเว็บและสร้างดัชนีจริงบน CPU จากคลัง 5,127 มาตรา](docs/screenshots/getting-started.png)

ภาพผลคำสั่งด้านบนจัดรูปจาก stdout จริง โดยเลือกบรรทัดสำคัญของการสร้างดัชนีเพื่อให้อ่านง่าย

| ค่าที่ใช้บ่อย | อยู่ที่ไหน |
| --- | --- |
| เลือก CPU หรือ GPU | `--device cpu` หรือ `--device cuda` |
| จำนวนคำถามและ seed ของการทดลอง | `thai-legal-rag run --help` |
| โฟลเดอร์ดัชนีและผลทดลองที่จะแสดงบนหน้าเว็บ | `thai-legal-rag-web serve --help` |
| รุ่นข้อมูลและโมเดลที่ใช้จริง | `manifest.json` ในโฟลเดอร์ผลรันหรือโฟลเดอร์ดัชนี |

![ผลคำสั่ง serve --help แสดงตัวเลือกดัชนี ผลประเมิน อุปกรณ์ และโหมดค้นอย่างเดียว](docs/screenshots/configuration.png)

ภาพนี้จัดรูปจากผลคำสั่ง `thai-legal-rag-web serve --help` ที่รันจริง

## ร่วมพัฒนา

เมื่อต้องแก้วิธีค้นหรือเกณฑ์วัดผล ให้อธิบายใน Pull Request ว่ากระทบไฟล์ผลรันและการเทียบกับผลเดิมอย่างไร ถ้าแจ้งปัญหาการรัน ให้แนบคำสั่ง ข้อความผิดพลาด และรุ่นข้อมูลหรือโมเดลจาก `manifest.json` หากมี

```bash
python -m unittest discover -s tests -v
npm --prefix frontend run build
```

![ผลทดสอบเดิมผ่าน 32 ข้อและ build หน้าเว็บสำเร็จจากการรันจริง](docs/screenshots/contributing.png)

ภาพนี้แสดงบางรายชื่อการทดสอบ พร้อมสรุปผลจริงทั้ง 32 ข้อและผล build หน้าเว็บ
